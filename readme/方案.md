# 自然语言转 FOFA 查询：实现方案

参赛包 `pkg-08e82c8d`，共 100 题。程序读取 `readme/题目.txt`，把每题自然语言填进 `查询语句`，写出可提交的 `答案.json`。

能转换时只输出一条可执行的 FOFA Query。不能转换时固定填写：

```text
该需求不能直接转换为FOFA搜索语句
```

不输出解释、不输出多条候选。参赛包编号保持 `pkg-08e82c8d` 不变。

## 1. 方案结论

用纯规则把句子编成查询，不用大模型。

原因：题目措辞稳定、评分看查询执行结果，规则可以单测、同一输入永远得到同一条查询。大模型会让结果飘，也测不住。

整条链路只有三层。中间只放一种结构（查询表达式），不再拆「意图层 / 领域服务层 / 仓储层」。

```text
题目 JSON
    │
    ▼
answer     读题、对题号、把最终字符串写回答案
    │
    ▼
convert    自然语言 → 查询表达式
    │
    ▼
fofa       表达式 → 一条 FOFA 字符串；不合法则拒绝
```

`cmd` 只负责把这三步串起来，不算一层业务。

## 2. 分层边界

| 层 | 目录 | 只做什么 | 不做什么 |
| --- | --- | --- | --- |
| 答案装配 | `internal/answer` | 读题目和模板、按题号回填、检查缺题/重复题/未知题号 | 不理解自然语言，不拼查询 |
| 句子转换 | `internal/convert` | 认字段、认且/或/非、查词表、处理外来语法 | 不负责引号转义，不写 JSON |
| 查询语句 | `internal/fofa` | 表达式、运算符、转义、端口/IP/自相矛盾校验、渲染 | 不出现中文题干 |

词表（国家、省、市、云厂商、产品别名）放在 `convert` 里的数据文件，不单独再做一层。

明确不做：

- 不为每个 FOFA 字段建接口或插件注册表
- 不引入通用语法解析库、规则引擎框架、依赖注入
- 运行时不访问网络。需要查文档或算图标哈希的题，事先算好常量写进代码
- 不猜。没有任何规则命中时，整题拒绝

## 4. 表达式与渲染

转换层只构造下面几种节点，渲染层负责变成字符串。

```text
Cmp   字段 + 运算符 + 值          port="80"    country!="CN"    cert.is_valid=true
And   左右都要满足                A && B
Or    左右满足一个                A || B
```

约定：

- 否定只挂在单个 `Cmp` 上（`!=`）。FOFA 没有通用的「对整段取反」，所以不造 `Not` 节点。
- 「至少两项非空」这类说法，在转换层展开成若干 `And` 再 `Or`，不增加新节点类型。
- 布尔值不加引号：`cert.is_valid=true`。普通文本一律双引号。
- 运算符只允许：`=`（包含）、`==`（精确）、`!=`（不包含）、`*=`（`*` 任意长度、`?` 单字符）。词表里没有的运算符一律不用。
- 括号只在 `&&` 与 `||` 混用时加上，保证先且后或不会被写反。

用词对应运算符，这条规则要有单测：

| 题干说法 | 运算符 |
| --- | --- |
| 是、为、等于、完整为、精确、名为 | `==` |
| 包含、带有、出现、里有 | `=` |
| 不是、不包含、排除、不要 | `!=` |
| 恰好 N 个字符、以某后缀结尾 | `*=`，用 `?` 和 `*` |

转义规则：值里的 `\` 和 `"` 先转义再包进双引号。M077、M078 的原样文本靠这条规则，不单独开特例通道。

## 5. 拒绝规则

命中任一条就整题返回固定拒绝句，不拼半截查询。

1. 端口不是 1 到 65535 的整数。M091 的 `1000000` 走这里。
2. IP 或网段用标准库解析失败。M092 的 `1.2.3.4.5` 走这里。
3. 同一字段在「精确等于」上互相打架。M093 要求国家代码既是 US 又不是 US，走这里。只检查 `country`、`region`、`city`、`port`、`ip`、`asn` 这种一块资产上不能同时取两个精确值的字段。标题里同时出现两个词不算矛盾。
4. 说的不是资产搜索能表达的条件：主观评价（M094「最安全」）、运行时指标（M095 容器内存）。
5. 没有任何规则命中。禁止用正文关键词硬凑一条查询。

## 8. 任务拆分

按顺序做。前一步的测试不过，不开始下一步。

### T1 骨架与答案装配

- 建立 `go.mod`（只使用标准库）、`cmd/nl2fofa`、三个 internal 包的空入口
- `answer` 读入题目和模板，按题号填 `查询语句`，参赛包编号原样保留
- 选手名称用命令行参数 `-name` 传入，不在代码里写死姓名
- 验收：缺题、重复题号、未知题号都会报错；包编号断言等于 `pkg-08e82c8d`

### T2 表达式渲染

- 实现 `Cmp` / `And` / `Or` 和渲染、转义
